# Release history

## 1.0.0 — 16 November 2026

Initial early-access Android release.

- Offline lecture recording with pause/resume, bookmarks and recoverable five-minute WAV parts.
- Local lecture library and audio playback.
- Optional Gemini/OpenAI processing using a personal API key and explicit upload confirmation.
- Transcript, editable notes, reviewer, practice quizzes, and PDF/text exports.
- Android Keystore-encrypted API keys and app-private lecture storage.
- Signed APK for Android 8.0 and later, installation guide, real device screenshots and published verification limits.

Live AI quality, hour-long real recording endurance, interruption recovery and broad device/accessibility coverage still require acceptance testing. See [VERIFICATION.md](VERIFICATION.md).
